# Hello There 👋 

I'm a hobbyist developer passionate about creating open source plugins for Minecraft servers. I love enhancing gameplay and contributing to the Minecraft community.

- 🔭 Currently, I'm developing plugins for the Minecraft server [skyblock.xyz](https://discord.gg/SyNvxSmSr7).

## 🌟 Featured Projects

- **[SkyLib](https://github.com/lukesky19/SkyLib)**: A utility plugin that provides shared code for my other projects, streamlining development and improving efficiency.
  
- **[SkyMines](https://github.com/lukesky19/SkyMines)**: Create dynamic mines with this plugin! It supports per-player mines using server-side tracking and packets to display blocks, as well as world-encompassing mines where players can unlock blocks.

- **[SkyHoppers](https://github.com/lukesky19/SkyHoppers)**: Enhance your item management with special hoppers that players can upgrade! Features include customizable suction speed, range, and transfer rates, all managed through intuitive in-game GUIs.
